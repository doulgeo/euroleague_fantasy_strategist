Day 1: starting lineup

The "golden rule": each full-scoring slot (5 starters + 6th man) prefers a player whose team plays on this round's earliest date over one who only plays later - projected value only breaks ties within the same availability, never overrides it. That keeps the slot flexible for day 2, instead of wasting it on someone who hasn't played yet. Formation defaults to whichever of 2-2-1 / 2-1-2 / 3-1-1 leads to the best simulated final total (force one with the dropdown above); captain is the highest-projected starter. Day 2: swap plan

A player marked DEMOTED already played on day 1 in a Starter/6th-Man slot and is being moved to the bench here - that halves the points they already earned playing day 1, it doesn't protect them. It's only worth it because the incoming player below is projected (or, if day 1's results are already in, actually scoring) higher than what this player just put up. A player marked PROMOTED is the flip side: moved from the bench into a full slot before playing, a pure gain (half points to full, no cost, since they hadn't played yet). {% if used_day1_actuals %} Day 1's actual results for this round have already been synced, so this swap plan is using their real scores (not just projections) for anyone who's already played. {% else %} Day 1 hasn't been played yet (or its results aren't synced - see Sync), so this plan is a pre-round best guess using projections for everyone - revisit it once day 1's actual results are in, since an underperforming/overperforming day-1 starter can change the right call. {% endif %}
